# Design system

The interface uses the supplied Aziz Jan Trust logo and a restrained navy, blue, off-white, slate, and white palette. Surfaces use thin borders, modest shadows, clear spacing, and compact status pills. Typography uses Inter for English and Roman Urdu and Noto Nastaliq Urdu for RTL Urdu content.

Reusable primitives include buttons, surfaces, citations, state panels, route skeletons, the application shell, and access-scope controls. Navigation, forms, review panes, search results, the policy reader, and the assistant share these primitives.

Every major data view provides a loading skeleton, empty content, service error, unauthorized response, and success state. Focusable native controls preserve keyboard access. Semantic landmarks, labels, status regions, readable contrast, responsive touch targets, reduced-motion preferences, and document-level RTL are included.

Desktop review uses two equal panes. Tablet and mobile stack the original before canonical editing. The employee navigation becomes a bottom navigation on narrow screens.
