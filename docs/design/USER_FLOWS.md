# User flows

## Employee

1. Authenticate with Firebase email/password inside the AJT login page, or select a clearly labeled fixture identity in local fixture mode.
2. Select English, Urdu, or Roman Urdu; the application keeps the selected language and direction.
3. Search published authorized SOPs or open the canonical policy reader.
4. Ask the assistant. Progress can be shown, while answer text appears only after citation and grounding checks pass.
5. Follow citations to canonical sections. Download an original only when the entire source is authorized.

## SOP administrator

1. Open the policy library limited to assigned management scope.
2. Create a version with explicit department, location, and role controls.
3. Upload or paste a source and inspect real parser availability.
4. Compare the private original with extracted canonical content and save controlled corrections.
5. Approve structure, stage and verify the retrieval index, inspect duplicates and version differences, then publish.
6. Review history, deactivate a policy, or roll back to a previously indexed version.

## System administrator

System administrators can manage unrestricted scopes and inspect tenant-scoped aggregate metrics and retrieval telemetry. Identity provisioning remains in the authoritative identity and organization data stores.
